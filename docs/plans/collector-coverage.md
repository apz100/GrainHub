One-page snapshot of every price-source adapter in the FastAPI
registry: what it is, whether its `[sources]` toggle is on, when it
was last verified live, and how many rows it returned then. Row
counts are **at last check, not live prices** — no prices appear in
this document.

**How it was built:** the per-adapter table below was generated by a
script (`/tmp/cycle39_coverage.py`, not kept in the repo) that reads
the live registry (`app/services/source_registry.py`, 119 adapters)
and the real toggle loader (`app/services/source_toggles.py`), and
merges a hand-compiled last-verified map drawn from the cycle
reports (Cycles 1–39) and the price-source catalogue. The script
asserts every adapter is in the map — nothing is silently guessed.
"Last verified" means the last cycle that called the adapter (or
its page/proxy) live with one polite GET and recorded the row
count; "Cycle 1" means the Cycle 1 pilot work, not re-verified
since.

**Status vocabulary:** `live` — returned rows at last check.
`stale-watch` — returned rows, but the widget header was one day
behind (exemption list for any future freshness gate; count
unchanged). `closed` — verified to return nothing, toggled off.
`off` — toggle off or stub, never returns rows on schedule.
`pending` — never live-verified; needs a browser render check or
a decision first.

**Headline numbers (Cycle 38 audit, re-confirmed here, corrected
Cycle 40):**
119 adapters; 101 toggle-enabled (seedable); 18 toggled off
(bunge, mapleview, 13 DTN, Heartland, Mulvane, andersons). Of the
101 enabled, 88 are `live` at last check, 5 are `stale-watch`
(they still return rows), and 8 are Ontario Playwright collectors
verified in Cycle 1 only. The `andersons` adapter targets a legacy
DTN host, was never re-verified, and is now toggled OFF — parked
2026-11-19 at Adam's request; do not probe that host. The
`north_gower` adapter is listed below as one ordinary adapter

   United Coop is the reverse (`[us]`-off + toggle-on) — the same
   shape as Collwest. The Cycle 18 sync guard deliberately compares
   only name/url/type/enabled between the two `[us]` lists, not
   toggles vs `[us]` enabled. No toggle change made.
