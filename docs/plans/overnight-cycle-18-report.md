### Mae-Mart proxy — identified (research, 1 GET)
- Re-fetch of `http://www.mae-martfarms.com/grain-pricing` (no
  saved HTML existed): the inline pricing JS names the proxy
  verbatim — `var PROXY = '/grain-proxy.php';`, called as
  `fetch(PROXY + '?symbols=' + encodeURIComponent(sym))`, one
  symbol per request, i.e.
  `http://www.mae-martfarms.com/grain-proxy.php?symbols=<SYMBOL>`.
- Symbols are Yahoo Finance format: `ZCZ26=F` (corn), `ZSF27=F`
  (soybeans), `ZWN27=F` (wheat); rye has no symbol (static
  `manualPrice`).
- **It returns futures quotes only, not cash bids:** JSON keyed by
  symbol, each entry with `price` and `currency`; `currency ===
  'USX'` means the price is in cents (client divides by 100).
  `USX` is the Yahoo Finance currency code for CBOT grain futures.
  Cash is computed client-side as futures + static basis — which
  is exactly why the collector's corn/soy/wheat rows carry basis
  with cash price empty.
- **Public vs licensed: upstream not confirmed.** Zero hits for
  Barchart/DTN/AgriCharts/Yahoo/Stooq/CME anywhere in the page, so
  it is not a visibly licensed feed. The `=F` symbols + `USX`
  handling are consistent with a relay of Yahoo Finance public
  quote data, but that is inference from client JS only — the
  proxy itself was deliberately **not** called.
- **Next probe (later cycle, 1 GET):**
  `GET http://www.mae-martfarms.com/grain-proxy.php?symbols=ZCZ26=F`
  — confirm response shape and whether the relay is live. Open
  decision for Adam/coordinator: using it would mean relying on
  the site's relay of third-party futures plus static basis to
  compute cash. No change to `mae_mart_source.py` this cycle.
